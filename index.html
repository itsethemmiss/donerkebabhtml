How It Works

1️⃣

Encode Tags

HTML tags are converted to kebab-encoded format within <donerkebabcode>

2️⃣

Preserve Special Tags

Script, style, and source attributes remain completely normal

3️⃣

Auto Transform

The donerkebabify.js library decodes tags at runtime

4️⃣

Render Normally

Browser displays fully functional HTML content
